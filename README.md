# Healthcare-Risk-Factors-Analysis-
The Healthcare Risk Factors Dataset contains patient demographic, lifestyle, and medical condition information used for healthcare analysis.The primary aim of this project is to analyze health-related risk factors and build predictive models using a  synthetic healthcare dataset containing 30,000 records.

# Sourse : from Kaggle , Source URL : https://www.kaggle.com/datasets/abdallaahmed77/healthcare-risk-factors-dataset
Aim:
Identifying key health risk factors (e.g., diabetes, hypertension, obesity)

Cleaning and preparing noisy/random data for analysis

Performing exploratory data analysis (EDA) to understand patterns and relationships

Building classification or predictive models to estimate disease risk or hospital stay length

Evaluating model performance and interpreting important features

 This project focuses on cleaning, preprocessing, and analyzing the dataset to improve data quality and generate meaningful healthcare insights.

# Overall Summary:

-Blood pressure increases with age.

-Higher glucose levels correspond with higher HbA1c values.

-Hypertension and diabetes are the most prevalent medical conditions.

-Higher BMI is commonly associated with metabolic conditions.

-Lifestyle factors such as stress, sleep, diet, and activity influence overall health outcomes.
